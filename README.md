# NekoLAB Hub

NekoLAB の VRChat アバター用ギミック（BOOTH で配っている物）に共通の「はじめに」画面です。
Unity のメニューの「NekoLAB」から開き、プロジェクトに入っている NekoLAB の商品を見つけて、アバターへの導入を手伝います。

The "Start" window shared by NekoLAB's VRChat avatar gimmicks (sold on BOOTH).
Open it from the "NekoLAB" menu in Unity: it finds the NekoLAB products in your project and helps you set them up on your avatar.

## 入れ方 / Install

NekoLAB の商品の説明書のとおり、ALCOM（または VRChat Creator Companion）に、次の一覧を足してから入れてください。

Add this listing to ALCOM (or the VRChat Creator Companion) as your NekoLAB product's manual says, then add "NekoLAB Hub" to your project:

```
https://nekolab-vrc.github.io/nekolab-hub/index.json
```

- インターネットにはつながりません。プロジェクトの外のファイルを読んだり書いたりしません。
  / It never goes online, and reads or writes nothing outside your project.
- Modular Avatar がなくても動きます（ある時は、同期パラメーターの使用量に Modular Avatar の分も数えます）。
  / It works without Modular Avatar (with it, its parts are counted in the synced parameters).
